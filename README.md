# AI Resume ATS Analyzer & Optimizer

A Streamlit web application that uses Google's Gemini 2.5 Flash model to evaluate resumes against specific Job Descriptions, generating ATS compatibility scores, skill breakdown, and step-by-step improvement recommendations.

## Features
- **PDF Parsing**: Automatically extracts readable text from PDF resumes.
- **ATS Compatibility Score**: Calculates match score (0-100%) against target job descriptions.
- **Keyword Gap Analysis**: Highlights matching skills and identifies missing critical keywords.
- **Actionable Feedback**: Provides recommendations to improve ATS ranking and readability.
